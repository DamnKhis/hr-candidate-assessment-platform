

# 🏛️ HR-Портал Мэрии Казани — Оценка мотивационного профиля кандидатов

Интерактивная HR-система для проведения первичного анкетирования, комплексного психологического тестирования мотивационной структуры кандидатов (методика Шейна / Мартина-Ричи) и автоматической генерации экспертных заключений с помощью искусственного интеллекта **GigaChat**.

---

## 📌 Ключевые возможности

- 📋 **Электронная анкета кандидата:** Сбор контактных, биографических и профессиональных данных (образование, опыт, карьерные ожидания).
- 🧠 **Тестирование мотивационного профиля:**
  - 33 вопроса с распределением ровно **11 баллов** между 4 вариантами ответа;
  - Автоматический подсчёт баллов по **12 факторам мотивации**;
  - Интерактивная валидация суммы баллов по каждому вопросу в реальном времени.
- 🤖 **AI-аналитика (GigaChat):**
  - Генерация психологического портрета кандидата;
  - Анализ пригодности для работы на государственной/муниципальной службе;
  - Выявление факторов риска и точек профессионального роста;
  - Итоговая рекомендация (*Рекомендован* / *Условно рекомендован* / *Не рекомендован*);
  - **Отказоустойчивый fallback:** локальный алгоритмический анализ при недоступности API или сетевых ограничениях.
- 📊 **Наглядная аналитика и отчёты:**
  - Диаграмма мотивационного профиля (Recharts);
  - Определение топ-3 ведущих мотиваторов и уровней выраженности факторов;
  - Встроенный редактор отчёта перед печатью/выгрузкой.
- 📄 **Экспорт и вывод данных:**
  - Скачивание официального отчёта в формате **Word (`.docx`)**;
  - Экспорт результатов в **JSON**;
  - Версия для прямой печати (`Ctrl+P`) с оптимизированными стилями.
- 🗂️ **Локальная база кандидатов:**
  - Автономная БД в браузере (на базе `localStorage`);
  - Поиск по ФИО и Email, просмотр истории и удаление записей;
  - Экспорт всей базы в файл `.json`.

## ⚙️ Установка и запуск

### 1. Требования
- Установленный [Node.js](https://nodejs.org/) (версии 18.0 или выше).

### 2. Клонирование и установка зависимостей
```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/hr-kazan-portal.git

# Перейдите в каталог проекта
cd hr-kazan-portal

# Установите зависимости
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корне проекта на основе `.env.example`:

```bash
cp .env.example .env
```

Добавьте в `.env` ключ авторизации GigaChat (Base64 строка `Client ID:Client Secret`):
```env
VITE_AUTH_DATA=ВАШ_BASE64_КЛЮЧ_ОТ_GIGACHAT_API
```

> ℹ️ **Примечание по GigaChat:**  
> Из-за CORS-политик браузера и самоподписанных сертификатов НУЦ Минцифры прямой запрос из браузера к `ngw.devices.sberbank.ru` может блокироваться. В этом случае приложение **автоматически переключается на встроенный экспертный модуль локального анализа**, не прерывая работу пользователя.

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется по адресу: `http://localhost:5173`.

### 5. Сборка для продакшена
```bash
npm run build
```

## 🔒 Безопасность и хранение данных

Все персональные данные кандидатов и результаты тестирования по умолчанию сохраняются исключительно в `localStorage` браузера пользователя (`hr_kazan_db`). Данные не передаются на сторонние серверы, за исключением защищённого обращения к API GigaChat для текстовой интерпретации профиля.
